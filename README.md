# Traceveil — Independent Application Security

A static landing page for Shaswat Raj's proposed independent web-application and API security assessment practice. It describes services, approach, deliverables, indicative starting ranges, and authorization requirements.

## Local preview

Open index.html in a browser or serve this directory with any static file server.

## GitHub Pages

The repository includes a GitHub Actions workflow at .github/workflows/pages.yml. It publishes the repository root when commits are pushed to main and can be run manually from the Actions tab.

Set repository Settings → Pages → Build and deployment → Source to GitHub Actions. After the first successful deployment, the site is available at:

https://playlikeboy.github.io/traceveil/

## Editing

Update site content in index.html. Keep all pricing as indicative starting ranges and confirm exact scope before quoting. Preserve the written-authorization and scope limitations.

## Important note

Traceveil is a proposed service identity, not a claim of incorporation, certification, or a guarantee of security or compliance outcomes. Security testing is performed only after written authorization and an agreed scope/rules of engagement.
